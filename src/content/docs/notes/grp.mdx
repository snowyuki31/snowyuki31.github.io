import { Definition, Example, Proposition, Proof } from '@components/env';

[[モノイドの圏]] と同じ要領で、「群全体」を [[圏]] として扱う。
そのために、まず群どうしを結ぶ射を定める。

<Definition title="群準同型" id="def-group-hom">
群 $(G, \cdot)$ から $(H, \ast)$ への写像 $\varphi \colon G \to H$ が
**群準同型**であるとは、任意の $a, b \in G$ について

$$
\varphi(a \cdot b) = \varphi(a) \ast \varphi(b)
$$

が成り立つことをいう。
</Definition>

モノイド準同型と違って単位元の保存を要求していないが、群では
$\varphi(e_G) = \varphi(e_G \cdot e_G) = \varphi(e_G) \ast \varphi(e_G)$ の両辺に
$\varphi(e_G)^{-1}$ を掛ければ $\varphi(e_G) = e_H$ が**自動的に**従う
（逆元の保存 $\varphi(a^{-1}) = \varphi(a)^{-1}$ も同様）。

<Example title="指数写像" id="ex-exponent">
$x \in \mathbb{R}_{>0}$ を 1 つ固定する。整数をその冪に移す
$\varphi \colon (\mathbb{Z}, +) \to (\mathbb{R}_{>0}, \times)$、$\varphi(n) = x^{n}$
は、加法を乗法に移す準同型である（$x^{m+n} = x^{m} \times x^{n}$）。
</Example>

準同型の条件は、「先に演算してから移す」と「移してから演算する」が一致すること、
すなわち次の図式が可換であることに他ならない。

```tikz
\usepackage{tikz-cd}
\usepackage{amssymb}
\begin{document}
\begin{tikzcd}[row sep=huge, column sep=huge]
\mathbb{Z}\times\mathbb{Z} \arrow[r, "+"] \arrow[d, "\varphi\times\varphi"'] & \mathbb{Z} \arrow[d, "\varphi"] \\
\mathbb{R}_{>0}\times\mathbb{R}_{>0} \arrow[r, "\times"'] & \mathbb{R}_{>0}
\end{tikzcd}
\end{document}
```

<Example title="部分群の包含" id="ex-inclusion">
部分群 $N \leq G$ に対して、包含写像 $N \to G$、$n \mapsto n$ は準同型である。
</Example>

<Definition title="群の圏" id="def-grp">
群を対象、群準同型を射とする圏を**群の圏** $\mathbf{Grp}$ と呼ぶ。
</Definition>

これが圏の公理を満たすことの確認は [[モノイドの圏]] と同様である
（恒等写像は準同型、準同型の合成は準同型、単位律・結合律は写像の合成から従う）。

<Proposition title="Grp のモノ射は単射" id="prop-mono-injective">
群準同型 $\varphi \colon K \to G$ について、次は同値である。

1. $\varphi$ は [[モノ射・エピ射|モノ射]] である
2. $\varphi$ は単射である
</Proposition>

<Proof>
$2 \Rightarrow 1$: $\varphi \circ f = \varphi \circ g$ なら、各元 $y$ で
$\varphi(f(y)) = \varphi(g(y))$ であり、$\varphi$ の単射性から $f(y) = g(y)$、
すなわち $f = g$。

$1 \Rightarrow 2$: $\varphi(a) = \varphi(b)$ とする。準同型 $f, g \colon \mathbb{Z} \to K$ を
$f(n) = a^{n}$、$g(n) = b^{n}$ で定めると
$\varphi(f(n)) = \varphi(a)^{n} = \varphi(b)^{n} = \varphi(g(n))$、
すなわち $\varphi \circ f = \varphi \circ g$。$\varphi$ はモノ射だから $f = g$、
特に $a = f(1) = g(1) = b$。
</Proof>


<Proposition title="Grp における部分対象は部分群" id="prop-subobject-subgroup">
群 $G$ の [[部分対象]] と $G$ の部分群は 1 対 1 に対応する。
対応は、モノ射 $\varphi \colon K \to G$ に部分群
$\varphi(K) = \{\, \varphi(x) \mid x \in K \,\} \leq G$ を割り当てることで与えられる。
</Proposition>

<Proof>
モノ射 $\varphi \colon K \to G$、$\varphi' \colon K' \to G$ について
$\varphi \sim \varphi'$ と $\varphi(K) = \varphi'(K')$ が同値であることを示せばよい。

$\varphi \sim \varphi'$ とすると、$\varphi = \varphi' \circ u$ となる $u$ が存在するので
$\varphi(K) = \varphi'(u(K)) \subseteq \varphi'(K')$、逆向きも同様で
$\varphi(K) = \varphi'(K')$。

逆に $\varphi(K) = \varphi'(K')$ とすると、$\varphi'$ は単射だから
$u = (\varphi')^{-1} \circ \varphi \colon K \to K'$ が定まり
（各 $x \in K$ で $\varphi(x) \in \varphi'(K')$ なので行き先がある）、
$\varphi = \varphi' \circ u$。逆向きも同様で $\varphi \sim \varphi'$。

また、どの部分群 $H \leq G$ も包含 $H \hookrightarrow G$ というモノ射から
$\varphi(H) = H$ として得られるので、対応は全射でもある。
</Proof>

この対応のもとで、部分対象の順序 $\leq$ は部分群の包含関係 $\subseteq$ と一致する。

この圏の中で群論の基本概念を捉え直す続きは [[群準同型の核と像]] へ。

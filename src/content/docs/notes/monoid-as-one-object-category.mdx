import { Example } from '@components/env';

[[モノイド]] の圏論的定義と古典的定義が一致することを確かめる。

<Example title="モノイドは対象が1つの圏" id="ex-monoid">
対象を $\ast$ ただ 1 つとし、$\mathcal{C}(\ast, \ast)$ を古典的な意味のモノイド $(M, \cdot, 1_M)$ の元全体とする。
射の合成を $\cdot$、恒等射を $1_M$ とすれば、モノイドにおける結合律と単位律はそのまま圏の公理になる。

逆に対象 1 つの圏 $\mathcal{C}$ から $M := \mathcal{C}(\ast,\ast)$ を取ると、$M$ はモノイドになる。

すなわち、対象が 1 つの圏はモノイドと同じである。
</Example>
